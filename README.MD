# ✈️ NTI Flight Management System

A Python-based Flight Management System developed as part of the **NTI Python Training Program**.

## 📌 Project Overview

This project provides a system for managing aircraft, hangers, flights, and customer reservations.

The project demonstrates Python programming concepts including:

* Object-Oriented Programming (OOP)
* Functions and modules
* CSV file handling
* Data processing
* Exception handling
* Flask backend
* Flight reservations
* Aircraft and hanger management

## 🛠️ Technologies Used

* Python
* Flask
* Pandas
* CSV
* HTML/CSS
* Git & GitHub

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/NTI-Flight-Management-System.git
```

Navigate to the project:

```bash
cd NTI-Flight-Management-System
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

Run the Flask application:

```bash
python app.py
```

Then open the local address displayed by Flask in your browser.

## ✈️ Main Features

### Aircraft Management

* Display aircraft information
* Search for aircraft
* Manage aircraft status

### Hanger Management

* Display hanger information
* Search hangers
* Track aircraft assigned to hangers

### Flight Reservations

* Create flight reservations
* Store customer information
* Generate confirmation information

### Web Backend

The project also includes a Flask backend that allows the Python functionality to be connected to a frontend interface.
